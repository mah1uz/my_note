# Testing and Correction Records

This folder records the verification work for each project part.

Each record distinguishes between:

- Tests actually executed.
- Problems found during verification.
- Corrections applied.
- Tests that are planned but cannot run until a later part exists.

Only project files inside `/mnt/d/A1/my_note` belong to the `mah1uz/my_note` Git repository. The parent directory and unrelated projects are outside this repository boundary.
